# Эталонный список дефектов AresMarket (только для куратора)

Студентам этот файл **не показывать**. ID (B1…) удобны при разборе репортов.

Шкала: Severity (Blocker / Critical / Major / Minor / Trivial), Priority (High / Medium / Low).

Обогащено идеями из черновика Olympus Market.

## UI / ручное тестирование

- **B1. Сортировка «Цена ↑» (price_asc) сортирует по убыванию.**  
  `backend/main.py` — при `sort=price_asc` используется `desc()`. Видно в каталоге и в API. *(Major / Medium)*

- **B2. Поиск регистрозависимый и только по `name`.**  
  Описание и бренд не ищутся. «баллон» ≠ «Баллон». *(Major / Medium)*

- **B3. Копирайт в подвале: «© 2019».** Устаревший год на всех экранах. *(Trivial / Low)*

- **B4. Нет подтверждения пароля при регистрации** + слабая проверка сложности. *(Minor / Medium)*

- **B5. Кнопки «В корзину» / фильтр — класс `filter-btn-inconsistent`**, чуть другой padding. *(Trivial / Low)*

- **B6. Длинные названия** — clamp работает неидеально на узких экранах. *(Minor / Low)*

- **B7. Итог корзины** без округления — длинные float (`123.456789 Ṡ`). *(Minor / Low)*

- **B8. Фильтры багов** применяются только по кнопке «Фильтр», без авто-применения. *(Minor / Low)*

## API / бэкенд

- **B9. Марсианская локаль → 500.**  
  `GET /api/locale/mars` (и mrt, arean, martian). Переключатель 🌐 в шапке. *(Critical / High)*

- **B10. Остаток на складе не уменьшается** после `POST /api/orders`. Можно заказывать сверх stock. *(Critical / High)*

- **B11. Добавление в корзину сверх stock**, если товар уже в корзине — повторная проверка stock не выполняется. *(Major / High)*

- **B12. max_price** использует строгое `<` вместо `<=` (граничное значение не попадает). *(Major / Medium)*

- **B13. Несуществующая category** в фильтре — молча отдаёт все товары. *(Major / Medium)*

- **B14. Severity баг-репорта** с неизвестным значением молча заменяется на `medium` (нет 422). *(Minor / Medium)*

- **B15. DELETE /api/bugreports/{id}** — без авторизации, любой может удалить чужой репорт. *(Major / High — security)*

- **B16. Поиск/фильтр баг-репортов** case-sensitive. *(Minor / Medium)*

- **B17. Нет total count** в списке продуктов (пагинация неудобна). *(Minor / Low)*

- **B18. Сообщение «Not enough stock»** не указывает доступное количество. *(Minor / Low)*

## Данные / SQL / бизнес-логика

- **B19. Отзывы:** один пользователь может оставлять несколько на один товар; `product.rating` не пересчитывается. *(Major / Medium)*

- **B20. PATCH корзины quantity=0** — удаляет item, но ответ может быть неожиданным для клиента. *(Minor / Medium)*
