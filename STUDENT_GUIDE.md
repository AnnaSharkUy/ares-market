# AresMarket — инструкция для студента

Добро пожаловать на учебный стенд **AresMarket** — марсианский интернет-магазин.  
Это не «игрушка ради игры»: приложение специально сделано с дефектами, чтобы Вы научились их находить и оформлять.

---

## 1. Что это такое

| Вопрос | Ответ |
|--------|--------|
| Что за продукт? | Учебный маркетплейс колонии Марса (каталог, корзина, заказы, отзывы) |
| Зачем мне? | Практика функционального, UI и API-тестирования + навык баг-репортов |
| На чём работает? | Веб: открывается в браузере (компьютер и телефон) |
| Валюта | **Sols (Ṡ)** — основная; Credits (₡) — справочно |
| Где оформлять баги? | Прямо в приложении → меню **«Баг-репорты»** |

Документ с требованиями (на английском): `TECHNICAL_REQUIREMENTS.md`  
Страница внутри приложения: **«Как тестировать»**

---

## 2. Что нужно на компьютере

- **Python 3.10+** (проверьте: `python3 --version`)
- Браузер: Chrome / Firefox / Edge / Safari
- Терминал (командная строка)
- По желанию: Postman или аналог для API

Если Python ещё нет:
- Windows: https://www.python.org/downloads/ (оставьте галочку «Add to PATH»)
- macOS: `brew install python` или с python.org
- Linux: `sudo apt install python3 python3-venv python3-pip`

## 3. Как скачать и запустить

### Вариант А — с GitHub (предпочтительно)

```bash
git clone https://github.com/AnnaSharkUy/ares-market.git
cd ares-market
```

### Вариант Б — если папку уже дали архивом

Распакуйте архив и откройте терминал **внутри** папки `ares-market`.

### Установка и запуск (Linux / macOS)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### Установка и запуск (Windows, PowerShell)

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

В терминале должно появиться что-то вроде:

```text
Uvicorn running on http://0.0.0.0:8000
```

Откройте в браузере:

| Что | Адрес |
|-----|--------|
| **Приложение (UI)** | http://localhost:8000 |
| **Swagger (API)** | http://localhost:8000/api/docs |

Остановка сервера: в терминале нажмите `Ctrl + C`.

> Если порт 8000 занят, запустите на другом:  
> `uvicorn backend.main:app --reload --host 0.0.0.0 --port 8001`  
> и откройте http://localhost:8001

## 5. Что попробовать за 15–20 минут (маршрут новичка)

Выполняйте по порядку и **записывайте всё странное**.

### Шаг 1. Осмотр главной
1. Откройте http://localhost:8000  
2. Посмотрите блоки, меню, подвал сайта.  
3. Откройте сайт на телефоне или сузьте окно браузера (проверка адаптива).

### Шаг 2. Каталог
1. Меню → **Каталог**  
2. Попробуйте:
   - фильтр по категории  
   - цену «от / до»  
   - сортировку (цена ↑, цена ↓, рейтинг, название)  
   - поиск по словам вроде `баллон`, `Баллон`, `скафандр`  
3. Откройте карточку любого товара.

### Шаг 3. Корзина и заказ
1. Войдите как `nova` / `nova123`  
2. Добавьте 1–2 товара в корзину  
3. Измените количество, удалите позицию  
4. Оформите заказ (укажите колонию доставки)  
5. Откройте **Заказы** — заказ должен появиться  

### Шаг 4. Локаль
1. В шапке нажмите 🌐  
2. Выберите любую локаль 

### Шаг 5. Баг-репорт
1. Меню → **Баг-репорты** → **Оформить баг-репорт**  
2. Заполните все поля по одному из найденных дефектов  
3. Отправьте и убедитесь, что репорт появился в списке  

### Шаг 6. API (по желанию)
1. Откройте http://localhost:8000/api/docs  
2. Разверните `GET /api/products` → **Try it out** → **Execute**  
3. Попробуйте `GET /api/locale/mars`

## 6. Как правильно оформлять баг-репорт

В форме приложения заполняйте:

| Поле | Что писать |
|------|------------|
| **Заголовок** | Кратко: что и где сломано |
| **Дисциплина** | UI / API / Локализация / Валидация… |
| **Шаги** | 1. … 2. … 3. … (чтобы повторил другой человек) |
| **Ожидаемый результат** | Как должно быть по здравому смыслу / требованиям |
| **Фактический результат** | Что увидели вы |
| **Severity** | blocker / critical / major / minor / trivial |
| **Окружение** | Например: Chrome 128, Windows 11 |

Пример заголовка:  
`Сортировка «Цена ↑» показывает товары от дорогих к дешёвым`

## 8. Если что-то не запускается

| Проблема | Что сделать |
|----------|-------------|
| `python3: command not found` | Установите Python 3 и перезапустите терминал |
| `pip` не находится | Используйте `python3 -m pip install -r requirements.txt` |
| Порт занят | Запустите на порту 8001 (см. выше) |
| Страница не открывается | Проверьте, что uvicorn всё ещё запущен в терминале |
| «Странные» данные после экспериментов | Остановите сервер, удалите файл БД `ares_market.db` (если есть) и запустите снова — данные пересоздадутся |
| Ошибки зависимостей | Убедитесь, что виртуальное окружение **активировано** (`(venv)` в начале строки терминала) |

## 9. Правила учебной работы

1. **Не правьте код**, пока ментор не попросил исправить баги.  
2. Сравнивайте поведение с здравым смыслом и с `TECHNICAL_REQUIREMENTS.md`.  
3. Все находки фиксируйте в **Баг-репортах** приложения.  
4. Проверяйте и UI, и API (Swagger).  
5. Проверьте и компьютер, и узкий экран (мобильный вид).
