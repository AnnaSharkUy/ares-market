# AresMarket — инструкция для студента (новичка)

Добро пожаловать на учебный стенд **AresMarket** — марсианский интернет-магазин.  
Приложение специально содержит дефекты: ваша задача — находить их и оформлять баг-репорты.

---

## 1. Что это такое

| Вопрос | Ответ |
|--------|--------|
| Что за продукт? | Учебный маркетплейс колонии Марса |
| Зачем мне? | Практика UI / API / ролей / локализации / форм с файлами |
| Где оформлять баги? | Меню **«Баг-репорты»** |
| Требования | `TECHNICAL_REQUIREMENTS.md` |
| Подсказки в UI | **«Как тестировать»** |

**Валюта:** Sols (Ṡ) — основная; Credits (₡) — справочно.

## 2. Роли (важно для сценариев)

| Роль | Как войти | Что можно |
|------|-----------|-----------|
| **guest** | Без входа | Каталог, карточка товара, локаль, guide, обратная связь, список баг-репортов |
| **colonist** | `nova` / `nova123` или своя регистрация | + корзина, заказы, отзывы. **Нельзя:** удалять баг-репорты, смотреть чужую обратную связь, админ-панель |
| **admin** | `admin` / `admin123` | Всё, что colonist, + удаление баг-репортов, список всей обратной связи, раздел **Админ** (пользователи, все заказы) |

Проверьте негативные кейсы: под colonist вызовите удаление репорта или `GET /api/feedback` / `GET /api/admin/users` — ожидайте **403**.

## 3. Запуск

### 3.1. Через Python (локально)

**Нужно:** Python 3.10+, браузер, терминал.

```bash
git clone https://github.com/AnnaSharkUy/ares-market.git
cd ares-market

python3 -m venv venv
source venv/bin/activate          # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

| Что | URL |
|-----|-----|
| UI | http://localhost:8000 |
| Swagger | http://localhost:8000/api/docs |

Остановка: `Ctrl + C`.

### 3.2. Через Docker (рекомендуется для группы)

**Нужно:** Docker Desktop или Docker Engine + Compose.

```bash
git clone https://github.com/AnnaSharkUy/ares-market.git
cd ares-market
docker compose up --build
```

Откройте http://localhost:8000  

Данные (БД и загруженные файлы обратной связи) хранятся в volume `ares-data`.

Остановка:

```bash
docker compose down
```

Другой порт:

```bash
PORT=8001 docker compose up --build
```

## 4. Маршрут новичка (20–30 минут)

1. **Главная** — осмотр UI, сузить окно (мобильный вид).  
2. **Каталог** — фильтры, поиск (`баллон` / `Баллон`), сортировка цены ↑/↓.  
3. **Без входа** — попробуйте корзину (должны направить на логин).  
4. **Вход** `nova` / `nova123` — корзина → заказ → раздел «Заказы».  
5. **Локаль 🌐**  
   - RU и EN  
   - **Марсианский** — смотрите и на **укороченные пункты меню**, и на **сообщение об ошибке 500** (два разных эффекта).  
6. **Обратная связь** — отправьте форму с 1–4 файлами разных типов и размеров.  
7. **Баг-репорты** — оформите найденный дефект.  
8. **Выйти → войти как admin** — раздел **Админ**, удаление репорта, список feedback.  
9. **Swagger** — `GET /api/locale/mars`, `GET /api/locale/mars/crash`, `GET /api/admin/users` под разными токенами.

## 5. Обратная связь (форма с вложениями)

**Меню → Обратная связь**

- Доступна **гостю и колонисту**.  
- Поля: имя, email, категория, оценка, тема, сообщение, файлы.  
- В UI указано: до **3 файлов**, до **5 МБ**, типы PDF / изображения / DOC / CSV / XLSX / TXT.

Имеет смысл проверить:

- 0 файлов, 1, 3, **4** файла  
- файл чуть больше 5 МБ и заметно больше  
- «странный» тип файла (например `.zip` / без расширения)  
- email без `@`  
- оценку вне диапазона 1–5  
- список всех обращений: `GET /api/feedback` под colonist vs admin  

Список всех обращений в UI/API — **только admin**.

## 6. Локаль: два уровня проверки

| Действие | Что ожидать при исследовании |
|----------|------------------------------|
| `GET /api/locale/ru` или `en` | Успех |
| `GET /api/locale/mars` | **200**, словарь с **урезанными / чужими** строками |
| Выбор «Марсианский» в UI | Меню может стать «Главн», «Корзин»… **и** появиться toast с **HTTP 500** |
| `GET /api/locale/mars/crash` | Стабильный **500** (удобно для API-тестов) |

Оформляйте наблюдения отдельно: «битые строки» ≠ «ошибка 500» — это разные дефекты с точки зрения тест-дизайна.

## 8. Если не запускается

| Симптом | Действие |
|---------|----------|
| Нет `python3` | Установить Python 3, переоткрыть терминал |
| Порт занят | `--port 8001` или `PORT=8001 docker compose up` |
| Нет Docker | Использовать вариант с Python |
| «Грязные» данные | Python: удалить `ares_market.db` и перезапустить; Docker: `docker compose down -v` (сотрёт volume) |
| 401 на корзине | Вы не залогинены — это ожидаемо для guest |
